# 岗位筛选助手

独立的 Chrome / Edge 浏览器插件，版本 0.1.3。通用网页识别，不内置具体公司名称、招聘域名、招聘接口或专用采集入口。

## 使用

下载 [v0.1.3 安装包](https://github.com/keyingdm/job-screen-assistant/releases/tag/v0.1.3)，解压后加载扩展。首次公开版本为 0.1.0；此前本地试制版本的收藏仍使用原扩展身份读取。

1. 解压安装包，在扩展管理页启用开发者模式，加载包含 manifest.json 的文件夹。源码安装选择 extension 文件夹。
2. 打开招聘列表，先选好原网站的公司、城市和招聘类别，再点击工具栏插件图标。
3. 工具栏打开当前网站的小窗；点击“开始检索”，沿用原页条件，从当前页读取后续分页。不同网站各自启动，不自动检索其他已打开的网站。
4. 小窗可设置“我的学历”、隐藏学历明确不符的岗位，并滚动查看全部筛选结果、岗位学历、具体冲突原因。“查看原岗位”与收藏并列显示，点击在新标签页打开岗位；“打开总筛选台”可设置完整条件，在表格或卡片中切换来源或合并查看，点击岗位查看右侧原文。
5. 小窗“×”只收起，任务继续。“结束并清空”停止该任务并清除未收藏结果；总台选择合并来源时，该按钮作用于全部本轮任务。

下次打开只显示收藏。请保持总筛选台标签页打开，切换到其他标签页即可；普通结果和任务进度只留在总台内存，刷新或关闭总台会清空全部本轮结果并停止采集。暂停和普通中断后显示“继续本次采集”，保留已发现岗位与已完成详情；每页发现后立即补读该页专业要求，再继续翻页。只有“重新开始并清空进度”才清空进度并从原招聘页当前页重新采集；启动预检失败时保留旧结果。小窗每4秒核对总台状态，连接中断时保留结果并提示重连，恢复后手动继续。小窗与总台均可选择当前来源的采集速度：默认稳妥3秒、可选较快2秒；采集中需先暂停再修改，同站任务采用较慢设置，速度只在本轮保留。个人条件和显示方式可保留。

浏览另一个标签页时继续采集；把正在采集的原标签页导航到别的网站时，在下一次来源检查停止原任务，已经发出的单次读取可能先完成。原页、总台都需保持打开。

## 专业筛选

“我的完整专业”用于资格判断；“专业检索词”支持任意部分名称和逗号分隔的多个词。检索仅针对独立专业字段和专业条款，设备、技能、工作经验不作为专业命中。默认显示命中、专业不限及信息不明的岗位，也可切换“只看专业词命中”。表格、卡片和详情显示依据；检索命中不代表满足专业资格。

内置[教育部2026年本科专业目录](https://www.moe.gov.cn/srcsite/A08/moe_1034/s3882/202604/W020260427440749576927.pdf)的883个专业、92个专业类、13个学科门类，离线运行。专业类关系只对已设置本科且完整名称已识别的条件提供参考；“理工类”“工科类”等给出范围依据并保留待核对，研究生、专科、历史目录或企业自定范围不自动套用。完整专业明确出现与优先、排除分别处理；明确排除优先于“专业不限”。

详情读取支持人资资格、任职资格及带括号栏目，也补查单个详情中的专业条款和结构化职位描述里的资格要求。识别“理学、工学等相关专业”这类并列范围，专业条款与同段技能分别处理。专业匹配岗位默认靠前，其他硬性冲突靠后；匹配的专业名称单独置顶、加粗并高亮检索词，完整原文继续保留。

读取完成仍未提取专业条款时，表格、卡片和小窗突出显示“未检测到专业要求”，不当作专业不限。待读、读取中、失败仍显示各自状态；已识别到宽泛或模糊范围时继续显示依据与待核对提示。

## 通用采集

识别常见岗位卡片、多层标题、结构化 JobPosting、详情标题、下一页和加载更多控件；公司链接和公司标题不另算岗位。没有分页时尝试向下滚动发现后续岗位。详情先读取 HTML，动态页面按来源分别使用非活动工作标签页加载；只读到学历摘要时继续等正文，不据此标为完整。详情标题不会覆盖列表中已有的岗位名称。当前岗位顶部摘要、表格、独立学历栏目与任职要求合并核对，保留学历“不限”“优先”“以上”等原文；列表已知学历在详情缺少该字段时保留并标注来源。顶部与正文学历不一致时提示待核对，不默认取较低要求。列表分页和滚动在原网页执行，以沿用已有条件。

保留跨站岗位详情链接。缺少详情站点权限时，保留已发现岗位并暂停，点击总台“授权详情站点并继续”后沿用本轮进度；小窗提供跳转授权入口。只申请实际遇到的详情站点，不默认授权所有网站。列表来源切换到另一网站仍停止原任务。

识别失败时可以点选岗位区域、标题和下一页按钮，并把选择规则保存在本机。支持能力取决于页面结构；不宣称任意网站都能全自动采集。未授权详情、跨站重定向、iframe、验证码和特殊交互可能需要手动处理。页面报告总量缺失时，覆盖情况显示未知。

自动翻页、滚动、详情点击与读取按实际访问站点默认共用至少3秒间隔（可选较快模式为2秒）；多个来源指向同一详情站点时也共用该站间隔。不设固定岗位数、分页数或操作总数上限，直到列表结束、页面重复或没有新增岗位。翻页无新增时停止发现，仍补读已发现岗位详情。大列表分批发布进度，暂停时保留未展示的已发现岗位。保护停止不自动续读，也不会声称覆盖全量。

静态响应、采集来源及动态工作页可观察到的已授权详情文档/同源接口返回403或429时停止相关来源任务，不继续尝试其他岗位或动态回退。明确验证码或访问限制页面也停止。冷却期至少10分钟，并遵守更长的 Retry-After；冷却结束也不自动重试。webRequest 权限只用于状态观察，不修改请求、认证或响应，不上传监测数据。

限速针对插件主动发起的操作，不控制网页自行加载的资源和后台请求。验证码识别依赖常见可见文字与控件，特殊验证可能无法识别；这些措施不保证网站兼容、不被识别或当然符合网站条款。

## 数据

- 只自动保存收藏岗位，不保存普通岗位集。
- 收藏包含原文、工作内容、原网页链接、采集时间与投递状态；“已投递”由你手动记录。
- 旧版升级先迁移已收藏记录，再删除旧普通岗位集和标记。
- 收藏备份只含收藏；CSV 由用户主动导出当前全部筛选结果。
- 没有上传功能，没有远程模型调用，个人筛选条件不发送到招聘网站。

安装包只含扩展资源和通用离线说明，无真实岗位快照、账户、个人材料、采集日志或用户规则。完整使用步骤见[使用说明](使用说明.md)。

## 开发

检查命令：npm test、npm run test:extension、npm run test:collection、npm run test:recognition、npm run test:multisite、npm run test:access、npm run test:details、npm run test:boundaries。

目录生成工具为 tools/build_major_catalog.py，需 pypdf。它从官方 PDF 提取事实名称、代码、专业类及门类，检查883个唯一代码、92个专业类、13个门类，并记录原PDF的SHA-256及来源。目录不是招聘企业的接收承诺，不调用在线模型，也不自动更新。

AI 扩展接口已预留，默认未配置服务，没有模型请求。接入约定见[AI接口](docs/AI接口.md)；辅助建议必须带可在输入原文中核对的证据，不能直接覆盖本地资格判断。

先安装 Node.js 和 Python 3.10+，运行 npm install。浏览器检查使用隔离 Edge 和虚构网页；默认使用 Windows 标准 Edge 安装位置，其他平台请通过 BROWSER_PATH 指定支持加载解压扩展的 Chromium 浏览器。打包前运行 python tools/build_help.py 与 python tools/package_extension.py。本科目录已随代码附带，正常使用和打包不必重建目录。

网页预览命令：python tools/serve_demo.py --port 8089，仅能体验虚构数据；真实采集需要安装插件。
