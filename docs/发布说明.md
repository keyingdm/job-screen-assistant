# 岗位筛选助手 v0.1.5

网站小窗增加“收起助手”：收起为可随时展开的浮动按钮，采集继续运行。拖动标题栏或浮动按钮可移动位置，同站翻页后恢复，窗口缩小时自动保持在屏幕内。

- 点击展开恢复原任务及结果；原×隐藏小窗，可从工具栏重新打开。方向键微调位置，Home恢复默认位置。
- 收起后仍核对任务状态，避免停留在旧的“检索中”；位置及收起状态只保存为当前标签页会话元数据，不保存普通岗位。
- 合并之前0.1.4本地候选的编号去重、筛选数字与结果一致、独立专业栏目和顶部学历读取，以及已读但缺专业条款的提示；没有新增公司专用适配器。
- 修正“本科四级、硕士六级”的分学历英语判断，未知分组保留待核对。

验证范围和实际公开页面验收边界见仓库《验证记录》。浏览器回归使用隔离配置和虚构岗位，安装包仅含26项白名单扩展资源，不含真实岗位快照、采集日志、账户或求职材料。

更新：覆盖原解压安装目录后，在扩展管理页点击“重新加载”；刷新招聘网页，关闭旧总台再重新打开，确认版本0.1.5。保留原扩展身份可继续读取收藏。
