# 岗位筛选助手 v0.1.3

修复采集中断后没有继续入口、重新开始覆盖进度、小窗状态滞后的问题。插件改为每页发现岗位后立即读取该页详情与专业要求，再继续翻页。

- 小窗和总台显示“继续本次采集”；超时、重复页、空分页及临时消息断线保留已有岗位与检查点。连接恢复后由用户继续，不自动重试。
- “重新开始并清空进度”与继续分开；新任务权限和连接预检成功后，才从原招聘页当前所在页重建任务。收藏保留。
- 小窗每4秒同步任务状态，拒绝过期的忙状态；临时端口断开不再当作关闭总台清空进度。后台可恢复操作计数与上一访问间隔，普通岗位仍只留在总台内存。
- 读取到的数量与页面报告不一致时提示尚未采齐；保留默认3秒、可选2秒的同站间隔和原有访问保护。关闭或刷新总台仍清空未收藏岗位。

隔离浏览器与本机虚构岗位共151项检查通过，包含220条后翻页中断并续读完成260条、临时端口断线、丢失终态推送、乱序消息，以及35页700岗位完整翻页。后台重建元数据用新逻辑上下文验证；不宣称真实浏览器崩溃后能恢复岗位，也未定位用户实际网站本次中断的唯一触发原因。

安装包仅含26项扩展资源，无具体公司入口、硬编码招聘站点或求职材料。

更新：将本版资源覆盖原解压安装目录，在扩展管理页点击“重新加载”；然后刷新招聘网页并重新打开小窗。保留原扩展身份可继续读取收藏，刷新总台会清空旧版普通结果。
