# 岗位筛选助手 v0.1.6

扩展通用网页兼容性，修复有职位列表却发现0条、图标分页漏识别，以及单页应用返回列表后入口失效的问题。

- 按可见列标题识别 DIV 数据表格、原生表格和 ARIA 网格，合并固定列；混合链接和纯文字标题均可读取。
- 支持图标 next、禁用末页、数字页码和带括号的职位总数；拒绝误点申请、投递等按钮。
- 单页应用详情读取前清除上个岗位文档，返回后核对原列表并重新定位入口；保留招聘范围与租户身份。
- 合并页头学历、深层职位标题及专业栏目中的完整富文本，不因通用 content 类只读到一个正文模块。

本版仍为通用规则，不内置公司、招聘域名或专用接口。兼容性与真实公开页验收的具体范围及网络条件见仓库《验证记录》，不声称全部网站适用。

更新：覆盖原解压安装目录后，在扩展管理页点击“重新加载”；刷新招聘网页，关闭旧总台再重新打开，确认版本0.1.6。保留原扩展身份可继续读取收藏。
