# 岗位筛选助手 v0.1.0

首个公开版本，独立运行于 Chrome / Edge。

- 在招聘网站主动打开小窗并开始检索，各网站单独运行，总台可切换或合并来源。
- 通用识别岗位列表、分页、滚动与详情；支持静态和动态详情、跨站详情授权续读。
- 按学历、城市、专业及工作内容等条件筛选，显示专业命中、待确认与具体冲突依据。
- 未检测到专业条款时醒目显示“未检测到专业要求”；提供收藏和“查看原岗位”按钮。
- 仅收藏岗位长期保存，可记录投递状态、备份收藏及导出筛选结果 CSV。
- 小窗收起后任务继续；离开原网站、结束清空或关闭总台按对应规则停止。内置访问节奏、有限预算和拒绝后的停止保护。

安装：下载下方 ZIP，解压到固定文件夹，在浏览器扩展管理页打开开发者模式，选择“加载解压缩的扩展”。安装包内含离线使用指南。SHA256SUMS.txt 可核对安装包完整性。

从此前本地试制版切换时，请替换原加载目录后重新加载，以保留扩展身份和收藏；也可先备份收藏，加载公开版后导入。

119项本地检查通过。验证使用隔离浏览器和虚构网页，不代表所有真实招聘网站都可完整识别。专业范围推断保留待核对；AI 接口默认关闭，没有模型请求。安装包不含真实公司入口、招聘域名、岗位快照、求职资料、账号或日志。
