# 岗位筛选助手 v0.1.7

补充标题与图片详情按钮分离的岗位卡片、纯 DIV 数字分页，以及公司目录提示。

- 从卡片实际 href 找到公开详情，拒绝真正的申请、投递、登录和脚本链接。
- 识别 DIV 的“>”、当前页和完整连续页码；到达末页时停止，即使原站未标禁用。
- 补读独立城市、附近唯一公司标题；跟踪没有 form 的岗位筛选条件。
- 公司/单位目录不计为岗位。先进入目标公司岗位页再开始，各公司可分别开标签页并在总台合并。
- 排除版权页脚，避免混入任职要求；不内置公司域名、接口或专用入口。
