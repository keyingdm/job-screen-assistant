# 岗位筛选助手 v0.1.2

- 小窗与总台增加按来源选择的采集速度：默认稳妥3秒，可选较快2秒。先暂停、修改、继续，可保留本轮进度；新来源默认稳妥，速度仅在当前会话保留。
- 同一实际访问站点的任务采用较慢设置共用队列，切换模式不缩短上一动作间隔。详情完整性检查、403/429和验证码停止、冷却与不自动重试保持不变。
- 小窗复用未变化的岗位行，减少大量结果刷新时的重复创建；全部筛选结果、排序、收藏和原岗位入口继续显示。

143项本地检查通过，覆盖生产2秒/3秒与混合速度间隔、暂停改速续读、较快模式遇429停止，以及35页700岗位、学历和专业识别回归。测试使用隔离浏览器和虚构网页，不能证明所有真实网站兼容或允许2秒访问，整体提速取决于页面加载和网络。

下载ZIP后解压到原扩展加载目录，在扩展管理页点击“重新加载”；保留原扩展身份和收藏。SHA256SUMS.txt对应此发布的ZIP下载名。安装包附离线说明，不含真实公司入口、招聘域名、岗位快照、个人资料、收藏、密钥或日志。
